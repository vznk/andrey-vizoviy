# Andriy Vizoviy — сайт-візитка

Односторінковий сайт у стилі «link in bio»: працевлаштування в Польщі, візи, страхування, запрошення.
Чистий HTML/CSS/JS без збірки — просто відкрийте `index.html`.

## Структура

```
index.html       — вся сторінка (тексти, посилання, відгуки)
(стилі)          — вбудовані в index.html у блоці <style> (кольори — в :root на його початку)
js/main.js       — перегляд фото на весь екран, липка панель, шапка
img/             — фото (hero, andriy, avatar, og — прев'ю для соцмереж)
img/visas/       — фото готових віз
img/reviews/     — скріни відгуків
```

## Як додати новий відгук або фото візи

Кожне фото зберігається в кількох версіях: маленьке прев'ю для стрічки і повний розмір для перегляду,
у форматах WebP (легкий) і JPEG (запасний для старих браузерів).

⚠️ Фото з телефона містять GPS-координати місця зйомки. Перед публікацією їх треба прибрати —
тому нові фото не додавайте «як є»: передайте їх розробнику, він перекодує їх (з правильним поворотом,
без метаданих) і додасть у `img/visas/` або `img/reviews/` та в `index.html`.

## Як додати карту офісу (Google Business)

1. Google Maps → знайдіть офіс → «Поділитися» → «Вбудувати карту» → скопіюйте посилання з `src="…"`.
2. У `index.html` знайдіть у блоці `id="contacts"` закоментовану карту (`class="map"`), приберіть `<!--` і `-->`.
3. Вставте посилання замість `ВСТАВТЕ_ПОСИЛАННЯ_EMBED_З_GOOGLE_MAPS`, а посилання на профіль — замість `ПОСИЛАННЯ_НА_GOOGLE_BUSINESS`, допишіть адресу.
